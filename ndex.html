Guía de Despliegue Web

De Visual Studio Code a GitHub y Vercel (Paso a Paso)

Esta aplicación está diseñada con arquitectura Client-Side ML + Serverless-Ready para que puedas abrirla en Visual Studio Code, subirla a un repositorio de GitHub y publicarla gratis en Vercel sin servidores de pago ni caídas.

1. Estructura de Archivos en VS Code

Crea una carpeta llamada salvita-itgam-chatbot en tu computadora, ábrela en Visual Studio Code y guarda este archivo como index.html (o sepáralo en index.html, styles.css, ml-engine.js y intents.json).

2. Alternativa con Backend Python (Scikit-Learn + FastAPI)

Si tu profesor de Desarrollo de APPS Web Inteligentes te pide código en Python, usa TfidfVectorizer y MultinomialNB / LogisticRegression de scikit-learn expuestos en una ruta api/chat.py con FastAPI o Flask compatible con Vercel Serverless Functions.

3. Comandos Git para Subir a GitHub desde VS Code
git init
git add .
git commit -m "Feat: Chatbot Salvita ITGAM con Machine Learning y 50 eventos"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/salvita-itgam.git
git push -u origin main
4. Publicación Instantánea en Vercel

Entra a vercel.com con tu cuenta de GitHub, haz clic en "Add New Project" → "Import" junto a tu repositorio salvita-itgam y pulsa "Deploy". En 15 segundos tendrás un enlace público https://salvita-itgam.vercel.app accesible desde cualquier celular o PC.
